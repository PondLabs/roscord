Prototype verdict

What the model supports

Keep one native host seam; make presentation a policy.
  • Embedded mode uses CEF OSR with a CPU OnPaint texture as the contract.
  • Separate mode uses a host-owned windowed CEF browser and the same framed control/event protocol.
  • Windows accelerated paint is an opt-in copy path after the software path is stable.
  • Profiles, permission decisions, input/IME, popup routing, and shutdown stay host-owned.
What this does not prove
  • CEF binaries, sandbox bootstrap, signing, or package footprint.
  • Actual HWND, D3D11, IME, accessibility, or GPU-driver behavior.
  • Production Flutter plugin code. This file is the disposable decision aid.
