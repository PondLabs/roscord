    Guided walkthroughs

    Run evidence sequences a maintainer can inspect

    The release baseline: OSR pixels arrive at a Flutter texture in a Flatpak Wayland session. This checks navigation, framed JS IPC, account selection, focus and IME, resize, deny-by-default media permission, popups, and clean host shutdown.

      Expected evidence

      Wayland does not need a native browser child. Flatpak keeps the same OSR contract. The account profile is selected before the surface starts.

      The comparison mode: use the same host and OSR surface behind a roscord-owned window shell. This is a presentation choice, not a second CEF runtime. X11 makes window ownership and popup behavior easy to inspect.

        Expected evidence

        Starting the owned window after embedded mode reuses host semantics: profile, IPC, permissions, input, and shutdown remain identical.

        The explicit risk check: probe accelerated paint and native child embedding in a Wayland Flatpak environment. CPU OnPaint stays authoritative while GPU import and native child paths remain gated experiments.

          Expected evidence

          A gated path is recorded as a follow-up, never silently promoted to the production composition path. Shutdown must still be clean.

          What this probe can settle

          Evidence incomplete

            Working decision

            Keep one native cef_host with windowless/off-screen rendering and a CPU OnPaint fallback. Select the presentation mode at the shell seam: embedded texture or a roscord-owned window.

            • Wayland native child embedding stays blocked by the upstream gap.
            • GPU import is a gated optimization; it never replaces CPU pixels.
            • Flatpak is an environment to qualify, not a separate backend.
            • Raw CEF objects stay inside the host; IPC carries commands and events.

            Prototype only. It has no CEF dependency, native plugin registration, or persistence. Delete this directory after the decision is carried into production design.
